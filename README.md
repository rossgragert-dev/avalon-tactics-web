# Avalon Tactics — Web Deployment

Public static deployment for **Avalon Tactics**.

Current release: **v0.5.8 — The Greenwood Command**

This release adds Mission 04, **The Greenwood Command**, as the fourth required Silent Wood mission. It preserves the v0.5.7 hero color separation baseline and the existing combat, progression, Resonance, Call the King, dialogue, stealth/detection, landmark, and mobile portrait systems.

The main GitHub Pages URL launches v0.5.8. Previous releases remain archived under their versioned preview folders.
