# Avalon Tactics — Public Web Game

**Current playable release: v0.7.2 — The Team Assembles**

Play: https://rossgragert-dev.github.io/avalon-tactics-web/

Mission 01 introduces Robin alone; Tristan joins Mission 02; Marian joins Mission 03.
This release also includes the v0.7.1 distinct hero kits, v0.7.0 tactical enemy AI, universal stealth, End Turn, and the Grey Hunt.

This repository contains **public compiled web builds only**. The authoritative private development source stays in `rossgragert-dev/avalon-tactics`.

Previous public versions are preserved in their `preview/` directories.

## Play the current test build on iPhone (no HTML download)

**Permanent latest test URL:** https://rossgragert-dev.github.io/avalon-tactics-web/preview/latest/

**Versioned v0.8.1 URL:** https://rossgragert-dev.github.io/avalon-tactics-web/preview/v0.8.1/

The test page serves a compiled single-file game through ordinary HTTPS browser requests. Open in Safari, then optionally use Share → Add to Home Screen. New tested versions can update the permanent `preview/latest/` bookmark without replacing the public v0.7.2 home page. Mobile Safari may re-fetch some assets on a fresh visit depending on cache limits, but does not require a manual file download.
